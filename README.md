# 生物基礎 暗記プリント完全道場 📱

高校「生物基礎」の重要用語や、テストで迷いやすい「対（ペア）の用語」を、スマホ・PC・Chromebook でテンポよく覚えられる学習アプリです。

👉 **今すぐ遊ぶ**: https://tyama11.github.io/biology-anki-dojo/

---

## 📚 学習できる4つの分野

- 🧬 **No.1 細胞・酵素・DNA**
- 🧠 **No.2 神経とホルモン**
- 🛡️ **No.3 免疫**
- 🌿 **No.4 植生と生態系**

---

## 🎮 3つの学習モード

画面上部のタブから、学習スタイルを切り替えられます。

### 1. 🔴 デジタル赤シート ＆ 穴埋め
- **🔰 かんたん**：赤シートで隠れた部分をクリックしてめくりながら、重要文を確認できます。
- **🧪 ふつう**：右側の用語カードを選んで、空欄（`？`）に当てはめるテスト形式です。

### 2. ⚖️ 対（ペア）で覚える！
「細菌類と菌類」「交感神経と副交感神経」「一次遷移と二次遷移」など、テストで逆にして失点しやすい対の用語をセットで判別します。
- **🔰 かんたん**：用語カードにわかりやすい特徴のヒントが表示されます。
- **🧪 ふつう**：ヒントなしのカードで、意味を思い出しながら当てはめます。

> 💡 **クリアしるしについて**  
> 各分野の「かんたん」「ふつう」をクリアすると、ボタンやタブに **✅ クリア済** や **🌟 2/2済** のしるしがつきます。まずは全分野のクリアを目指しましょう！

---

### 3. 👹 鬼モード（総合タイムアタック）

**「赤シート」と「対（ペア）」の全4分野（かんたん・ふつう／計16ステージ）をすべてクリアすると解放される**、総仕上げのタイムアタックモードです。

#### 5つの問題形式がランダムで登場！
全分野から、短い問題文と **2〜3択** の選択肢でテンポよく出題されます。
- 📝 **穴埋め**：重要文の空欄に入る用語を3択から選ぶ
- ⚖️ **ペア判別**：短い特徴文に当てはまる用語を3択から選ぶ
- ⭕❌ **正誤クイズ**：ひっかけ文が「⭕ 正しい」か「❌ 誤り」かを2択で即答
- 🔄 **用語→意味**：提示された用語の正しい特徴を3択から選ぶ
- 🚫 **仲間はずれ**：お題に当てはまらないものを3択から1つ選ぶ

#### ルールと称号ランク
- **制限時間**：60秒
- **ミス**：`-3秒` のペナルティ
- **ボーナス**：5連続正解ごとに `+3秒` 回復！

## ⌨️ 便利な機能・操作方法

- **キーボード操作**：`Tab` で移動、`Enter` / `Space` で決定、`Esc` で選択解除ができます。
- **鬼モードのショートカット**：キーボードの `1` `2` `3` キーで、選択肢をそのまま素早く回答できます。
- **効果音のオン・オフ**：画面右上の「🔊 音ON / 🔇 音OFF」ボタンでいつでも切り替えられます（学校や図書館でも安心です）。
- **記録の保存**：クリア状況や鬼モードのベスト記録は、お使いのブラウザに自動で保存されます。
